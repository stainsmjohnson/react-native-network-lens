# react-native-network-lens

In-app HTTP network inspector for React Native with a tabbed request viewer, collapsible JSON tree, search and zero dependencies

## Installation


```sh
npm install react-native-network-lens
```


## Usage


```js
import { multiply } from 'react-native-network-lens';

// ...

const result = multiply(3, 7);
```
